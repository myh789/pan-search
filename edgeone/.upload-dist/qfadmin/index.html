夸克

如何获取夸克 Cookie
  1. 用 Chrome / Edge 打开 pan.quark.cn 并登录账号。
  2. 按 F12 打开开发者工具 → 切到 Network / 网络。
  3. 刷新页面，随便点开一个接口请求（例如含 clouddrive 的）。
  4. 在请求头 Request Headers 里找到 Cookie，整段复制。
  5. 也可：Application / 应用 → Cookies → https://pan.quark.cn，把主要项拼成 key=value; key2=value2（需包含登录相关字段，如 __pus 等）。
  6. 粘贴到下方 → 保存 → 点「测试登录」。成功后再选转存/临时目录。

Cookie 过期后前台转存会失败，重新按上面步骤更新即可。

百度

如何获取百度 Cookie
  1. 建议用浏览器 无痕/隐私模式，打开 pan.baidu.com 并登录。
  2. 按 F12 → Network / 网络，刷新页面。
  3. 点开任意 pan.baidu.com 请求，在 Request Headers 复制完整 Cookie。
  4. 也可：Application / 应用 → Cookies → https://pan.baidu.com，确保含 BDUSS、STOKEN 等关键字段。
  5. 粘贴到下方 → 保存 →「测试登录」→ 再选转存/临时目录（百度用路径，如 /转存）。

只贴 ab_sr 不够，必须能在 Cookie 文本里搜到 BDUSS=。转存失败时前台会回退原链（提取码不是 6666 即未转存成功）。多端登录易掉线（-4 / -6）。

迅雷

如何获取迅雷 refresh_token

迅雷填的是 refresh_token，不是浏览器 Cookie。

方法一（推荐）

  1. 打开 pan.xunlei.com 并登录。
  2. 按 F12 → Application / 应用。
  3. 左侧 Local Storage → 选中 https://pan.xunlei.com。
  4. 找到 credentials 或含 refresh_token 的项，复制 token 字符串。

方法二（抓包）

  1. 同上登录后切到 Network / 网络。
  2. 筛选 auth/token 或 signin/token。
  3. 打开响应 JSON，复制字段 refresh_token。

保存后点「测试登录」。登录成功后系统可能自动轮换并回写新的 token，以后以后台里最新值为准。

其它（暂不转存）

转存参数

全网搜固定「转存后分享」，不展示第三方原链。可配置验链与临时资源保留时间。

开启后前台先展示结果并显示「检测中」，再逐条验链（夸克/百度/迅雷）：有效保留，无效删卡。关闭则不显示检测字样。默认关闭。

前台「获取资源」写入临时目录；到期后自动从对应网盘删除（夸克/百度/迅雷）。默认 30 分钟，可点「立即清理」。

关闭后前台不显示对应网盘入口，也无法搜索该类型。至少保留一个开启。
