| 后台批量「转存分享导入」 | ✅ | ✅ | type=2 |
| 表格导入（仅入库） | ✅ | ✅ | |
| 分类全部转存 / 日更聚合 | ✅ | ✅ | 需 transfer_feed_url |
| Open API 同步转存返回分享链 | ✅ | ✅ | 默认同步；`async=1` 队列 |
